# 📈 TradeCalc Pro

An all-in-one trading calculator suite for Forex and retail traders built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🧮 Simple Calculator
- 🔬 Advanced Calculator
- 📈 Pip Calculator
- 💵 Pip → USD/INR Converter
- 💰 Position Size Calculator
- 🏦 Margin Calculator
- 🎯 Risk : Reward Calculator
- 📊 Compounding Calculator
- 📈 SIP Calculator
- 💹 Profit/Loss Calculator
- 💱 Currency Converter
- 🥇 Gold Calculator
- 📝 Trading Journal with Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Responsive Web Design
